## 컨셉 v2 — "소프트 글래스 (Soft Glass)"

iOS 계열의 밝고 공기감 있는 화면. **색 블롭(앰버·블루 radial) 위에 반투명 블러 카드**가
떠 있는 구조 — 배경이 은은하게 비쳐서 화면에 깊이가 생긴다. 산세리프 전환(세리프 제거),
큰 라운드(카드 18px), 알약형 컨트롤, 부드러운 그림자.

- **라이트가 주력**: 밝은 포슬린(`#EEF0F6`) + 채도 있는 블롭. 글래스는 흰 반투명.
- **다크는 톤 낮춘 다크 글래스**: 블롭 알파를 크게 낮추고(0.45→0.16) 글래스를 어두운 반투명으로.
- 액센트 = 블루(`#3556C8`/다크 `#8FA8F5`), Spotify green은 재생 버튼 전용 유지.
- intent 3색(모스/슬레이트/플럼)은 알약(pill)로 유지.
- 아트 타일(id 해시 그라디언트)은 그대로 — 글래스 위에서 색 포인트 역할이 더 커짐.
- 기술 노트: `backdrop-filter: blur()`(+`-webkit-` 접두) — 블롭이 실제로 비쳐 보이게 하는 핵심.
  블롭은 `body::before/::after` fixed + `z-index:-1` + `pointer-events:none`.

### 피해야 할 것 (AI 상투 디자인)
warm cream + terracotta, near-black + 형광 초록 단독 포인트, 보라-파랑 그라디언트 히어로,
이모지 섹션 마커, 전부 가운데 정렬. 이 목록에 걸리는 선택은 하지 않는다.

색 정의는 전부 `:root` 3단 가드 패턴으로: bare `:root`(라이트 전체) →
`@media (prefers-color-scheme: dark)`의 `:root:not([data-theme="light"])` →
`:root[data-theme="dark"]`. 컴포넌트는 토큰만 참조 — 미디어쿼리 안에 색 직접 정의 금지.

## 레이아웃 (모바일 퍼스트)

```
┌────────────────────────┐
│ 상단바: 타이틀 · 테마토글  │  sticky
│ 탭: 전체|내취향|클래식·교양|아이돌·가족 │  ← Q06 해결: intent 필터를 탭으로 승격
├────────────────────────┤
│ 오늘의 추천 (하이라이트 패널) │
│ 탐구 — 쿼리 빌더           │
│ 도구: 태그필터·추가·내보내기·설정 │  ← 접을 수 있게
│ 컬렉션 목록 (아트 타일 카드)  │
└────────────────────────┘
```

- **탭 = intent 필터의 승격** (Q06): 라벨을 "내 취향 / 클래식·교양 / 아이돌·가족"으로 —
  Nick의 "클래식과 아이돌 별도 탭" 요청을 별도 화면이 아니라 필터 승격으로 푼다
  (사용자 1명 전제 — 화면 분리는 과설계).
- **아트 타일**: 앨범아트 데이터가 없으므로 id 해시 → 결정적 그라디언트 + 첫 글자.
  외부 이미지 없이 음악 앱의 밀도를 만든다. 같은 엔트리는 항상 같은 색 (해시라서).
- 청취 시간이 짧은 사용자 → 스캔 우선: 추천 3개가 최상단, 액션(듣기 링크)이 카드에서 한 번에.

## 모션

- 카드: hover/press 시 미세한 translate+shadow (0.15s).
- 섹션: 최초 로드 시 위→아래 순차 fade-in 1회 (0.3s, stagger).
- `prefers-reduced-motion: reduce` → 전부 끔.
- 과한 모션 금지 — 모션이 많을수록 AI 생성 티가 남.

## 테마 토글

우상단 버튼, 순환: 시스템 → 다크 → 라이트 → 시스템. 선택은 `mma_theme` localStorage에.
시스템 상태(저장값 없음)에서는 `data-theme` 스탬프 없이 미디어쿼리만 동작.
