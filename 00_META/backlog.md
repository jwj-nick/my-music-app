# 백로그 — 다음 반복 아이디어

> 2026-08-23 자율진행 라운드 말미에 정리. "진행 완료되면 더 나은 아이디어 찾아보고 또 진행"
> (Nick 지시)의 수집함. 우선순위는 Nick 복귀 후 게이트(1.5.9·2.5) 통과 뒤에 정한다.

## 기능

- **B1. Spotify oEmbed로 실물 앨범아트**: `open.spotify.com/oembed?url=...`은 키 없이 앨범아트
  썸네일을 준다 — spotifyUrl이 채워진 엔트리부터 해시 타일을 실물 아트로 교체 가능.
  (제약: spotifyUrl을 아직 안 채웠음 — T1 탐구로 실제 트랙 URL 수집하는 흐름과 묶으면 자연스러움)
- **B2. 청취 통계 뷰**: mma_logs가 쌓이면 "이번 달 몇 회 / intent 비율 / 최근 연속" 같은
  소형 통계 패널. IBM Plex Mono + 미니 바 차트로 계기판 느낌 — 데이터는 이미 있음.
- **B3. 탐구 히스토리**: 보낸 쿼리·받은 답을 localStorage에 남겨 "지난 탐구 다시 보기".
  같은 질문 재전송(=재과금) 방지 효과도.
- **B4. T4 브리핑 → 메모 승격 버튼**: 지금 T4는 읽기만 — 브리핑의 한 항목을 골라 관련
  엔트리 메모로 붙이는 파이프 (T1/T3의 "+추가"와 대칭).
- **B5. 추천 로직에 청취 로그 가중치**: 지금은 "골고루+오늘 제외"뿐 — 로그가 쌓이면
  "자주 들은 태그 우선" 같은 규칙 추가 (recommend()에 opts로, 순수성 유지).

  옮기면 다음 세션에서도 재사용 가능. (세션 종속 경로 제거 필요)

  체감 대기 감소. (복잡도 증가 — 필요성 확인 후)
