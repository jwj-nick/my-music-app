# 미결 질문 — my-music-app

> 확인·검증·결정이 필요한 항목. 해결되면 답과 날짜를 달고 ✅.

- **Q01. ✅ (2026-08-22) 재생 소스 = Spotify 무료 계정 + 딥링크.** my-music-app 자체는 재생기를 만들지 않고, 곡 링크를 열어 Spotify 앱이 재생하게 위임한다. 로컬 음원 없음·유료 구독 없음이 전제. (검증 필요: Spotify 무료 계정의 백그라운드/잠금화면 재생 실동작 — 폰에서 5분 테스트로 확인 권장)
- **Q02. ✅ (2026-08-22) 기존 취향 데이터 없음.** 스트리밍 서비스에 쌓인 플레이리스트/좋아요 없음 — import가 아니라 이번 세션 대화로 정적 취향 데이터를 새로 만든다.
- **Q03. ✅ (2026-08-22) 폰 우선(모바일 퍼스트) 확정.** 최종 배포 목표가 안드로이드 APK이므로 자명.
- **Q04. ✅ (2026-08-22) 지식노트는 두 경로 병행으로 정리.** 깊은 리서치(클래식 후보처럼 출처가 필요한 것)는 Claude Code 세션에서 함께 — 짧은 메모는 마일스톤 1.5의 인앱 "메모 편집"으로 Nick이 그때그때. 두 경로 다 Phase 1에서 실제로 구현·검증됨.
- **Q05. ✅ (2026-08-22) intent 필드(taste/explore/family)로 분리 확정.** 스키마(마일스톤 1.1)에서 해결 — 아이들 취향은 `family`로 Nick 취향(`taste`)과 구분된다.
- **Q06.** 클래식·아이돌(가족탐구) 쪽 별도 탭/메뉴 — Nick 요청(2026-08-22, "나중엔"). intent/tag 필터만으로 충분한지, 아니면 상단 탭 같은 별도 내비게이션이 필요한지는 Phase 2(디자인 심화)에서 다룬다.
