# 미결 질문 — my-music-app

> 확인·검증·결정이 필요한 항목. 해결되면 답과 날짜를 달고 ✅.

- **Q01. (최우선) 재생 소스를 어디로 할 것인가** — 나머지 기능 설계 전부가 여기 종속된다.
  - YouTube IFrame API 임베드: 무료, 저작권 안전, 카탈로그 사실상 무한 / 광고·모바일 백그라운드 재생 제약.
  - 로컬 파일(본인 소유 음원): 무료, 완전한 통제, 오프라인 가능 / 음원 확보 필요, 기기 간 동기화 문제.
  - Spotify Web API: 무료 티어, 메타데이터·취향 데이터 풍부 / 전체 재생은 Premium 필요.
- **Q02.** "내 취향" 데이터가 이미 있는가 — 기존 플레이리스트나 좋아요 목록을 export할 수 있는지 확인 필요.
- **Q03.** 폰 우선인가 데스크톱 우선인가.
