# my-music-app

Nick 전용, 무료 운영을 전제로 한 개인 음악 앱. 범용 스트리밍 서비스를 흉내 내지 않고 사용자 1명(Nick)의 취향에만 맞춘다.

- **Phase 1 — 기능:** 라이브러리(플레이리스트+태그), 청취 기록 로그, 규칙 기반 추천.
- **Phase 2 — 디자인:** 앨범아트 그리드·타이포그래피·모션·다크/라이트 테마. 포트폴리오급 UI가 목표.
- **공개:** 처음부터 public repo. 완성되면 GitHub Pages 등으로 배포.

## 구조
- `00_META/` — 진행 상황 SSOT (`MASTER_PLAN.md`), 결정 기록, 미결 질문, 세션 로그.
- `10_app/` — 앱 소스 (Phase 1부터 채워짐).

## 현재 상태
Phase 0 — 방향 확정 전. 가장 먼저 풀어야 할 질문은 **재생 소스를 어디로 할 것인가** (YouTube 임베드 / 로컬 파일 / Spotify API) — `00_META/open_questions.md` Q01 참조.
